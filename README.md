# MM Cookies — Millet Melts

## Current order flow
Browse → Add to cart → Customer details → Order on WhatsApp → Thank-you screen.

There is **no online payment and no QR code** in the app. Payment is handled later through WhatsApp after MM Cookies confirms the order.

## Add your WhatsApp number
Open `index.html` and find:
`const CONFIG={whatsappNumber:""};`

Enter your WhatsApp number with country code and digits only, for example:
`const CONFIG={whatsappNumber:"919876543210"};`
